# Lupac: páginas de apoio

Páginas públicas de **privacidade e termos de uso** do [Lupac](https://github.com/lucianofonsecadev/lupac-plataforma),
plataforma que organiza e publica vídeos no YouTube, TikTok e Instagram.

O código do Lupac é privado. Este repositório guarda só estas páginas, que redes e serviços exigem como endereço público.

Site: https://lucianofonsecadev.github.io/lupac/

> O arquivo `tiktok….txt` na raiz é a verificação do domínio feita pelo TikTok. Não apagar.
